## 装服务端：从空系统到第一次启动

系统用 Ubuntu 或 CentOS 都行，下面命令按 Linux 写。

第一步要放通端口。腾讯云控制台的安全组里放行 2456–2458，系统自带的 firewalld 或 ufw 也要放行同样的端口。两层漏一层，外面就连不上。

第二步装依赖。steamcmd 是 32 位的，64 位系统上跑需要 32 位运行库：

bash
# Ubuntu / Debian
sudo apt-get -y install lib32gcc1
# 提示找不到这个包时，换成 lib32gcc-s1

# CentOS / RedHat
yum install -y glibc.i686 libstdc++.i686


第三步装 steamcmd 并拉服务端。Valheim 专用服务器的 Steam App ID 是 **896660**：

bash
mkdir ~/steamcmd && cd ~/steamcmd
curl -sqL "https://steamcdn-a.akamaihd.net/client/installer/steamcmd_linux.tar.gz" | tar zxvf -
./steamcmd.sh +force_install_dir ~/valheim +login anonymous +app_update 896660 validate +quit


`+login anonymous` 是匿名登录，不需要 Steam 账号，也不需要先买一份游戏。

把最后那条命令写进一个 `update.sh`，以后每次更新服务端重跑它就行，不用重装。第一次搭建议先按最小规模试通，跑顺了再考虑升配。👉 [腾讯云轻量应用服务器各档位实时价格](https://bit.ly/yunhuodong)

## start_server.sh 里的五个参数，两个有坑

服务端目录里有个 `start_server.sh`，需要改的是里面那串启动参数。

| 参数 | 作用 | 注意 |
| --- | --- | --- |
| `-name` | 服务器名称 | 显示在服务器列表里 |
| `-port` | 游戏端口 | 默认 2456，改了要同步改安全组 |
| `-world` | 世界名称 | 对应存档文件名 |
| `-password` | 进服密码 | 至少 5 位，且不能出现在服务器名称里 |
| `-public` | 是否公开 | 填 1 会出现在社区列表，填 0 只能靠 IP 直连 |

两个坑都出在密码上：少于 5 位，服务端起不来；密码字符串如果包含在服务器名称里，同样起不来。这个限制在文档里不显眼，踩了就是黑屏没反应，还找不到报错。

## 满屏 Shader ERROR，其实服务器已经在跑了

这是新手最容易放弃的地方。在一台没有显卡的云服务器上启动服务端，日志会连续刷出几十行类似这样的内容：


Forcing GfxDevice: Null
NullGfxDevice:
ERROR: Shader Sprites/Default shader is not supported on this GPU
ERROR: Shader UI/Default shader is not supported on this GPU


看着像彻底崩了，其实没有。专用服务器走的是 Null 渲染设备，根本不需要 GPU，这些是 Unity 在无显卡环境下的正常输出。

判断是否真的启动，看后面这几行有没有出现：

- `Steam game server initialized`
- `Builder started`
- `Valheim version: ...`

三个都出现了，说明服务端已经在运行。这时候游戏里还连不上，问题基本在端口或密码，不在服务端本身。

## 朋友搜不到服务器，按这个顺序查

搜不到、连不上，九成是下面四个原因之一，按顺序排查比反复重启服务端快得多：

1. **安全组没放行**。2456–2458 一条规则全放，别只开 2456。
2. **系统防火墙没放行**。云控制台开了，机器里的 firewalld/ufw 还拦着，一样不通。
3. **`-public` 填了 0**。服务器不会出现在社区列表里，得让朋友用 IP 直连。
4. **跨平台玩家**。队伍里有 Xbox 或 Microsoft Store 版本的玩家，需要在启动参数里加跨平台选项，具体写法按官方专用服务器指南确认，别照搬其他游戏的配置。

改完参数要重启服务端进程，光改 `start_server.sh` 不会自动生效。

## 存档、备份和搬家

Valheim 的服务端存档都在同一个目录下：


/home/steam/.config/unity3d/IronGate/Valheim


世界文件、角色数据和配置都在里面。备份就是把整个目录打包，迁移就是把整个目录复制到新机器上。换服务器不需要重新开图，这一点能让不少人少走弯路。

两个操作习惯值得养成：停掉服务端再复制，跑着复制可能拿到写了一半的文件；更新服务端之前先备份一次，更新完进游戏确认版本对得上，版本不一致会直接进不去。

## 常见问题

**搭服务器需要先买一份英灵神殿吗？**
不用。用 steamcmd 的匿名登录方式拉服务端，这条路径本身就不需要 Steam 账号。

**2 核 2G 能跑起来吗？**
能启动，也能进人。但世界探索范围一大、基地建筑一多，加载会变慢，三个人以上就容易顶到内存上限。新开服建议从 4GB 起步。

**服务器要一直开着吗？**
专用服务器进程不退，玩家随时能进。这正是它和「房主开游戏等人」最大的区别，不用凑时间。

**更新服务端会丢存档吗？**
正常更新不会动存档目录，但版本不一致时可能进不去。稳妥做法是更新前打包一次 `/home/steam/.config/unity3d/IronGate/Valheim`。
